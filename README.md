# FKIF — A Fuzzy Knowledge-Inference Framework for AI-Adoption Risk Assessment in Automotive SMEs

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/LoveleenGaur/FKIF_automotive_SME_risk/blob/main/FKIF_automotive_SME_risk_FINAL.ipynb)

Reproducible code for the paper *A Fuzzy Knowledge-Inference Framework for AI-Adoption Risk Assessment in Automotive SMEs*.

The **FKIF** is a two-stage rough–fuzzy inference framework for assessing the risk of AI adoption in automotive small and medium-sized enterprises (SMEs). Eight literature-grounded, automotive-specific risk factors are represented as linguistic variables over an information system; rough-set analysis establishes the non-redundancy of the taxonomy; and a hierarchical Mamdani inference process — anchored, compliance-weighted, and **non-compensatory** — produces an interpretable overall AI-Adoption Risk Index.

The framework uses **no primary human data**. It is validated through face validity at anchor points, the formal property of monotonicity, and **triangulated convergent validity** against two independent, mutually consistent readiness instruments (an operationalization of the Schumacher et al. Industry 4.0 maturity model and a TOE composite), evaluated on a realistic correlated SME population.

## Reproducibility

All stochastic steps use fixed random seeds, so every reported figure and statistic (convergent-validity coefficients, monotonicity rate, rough-set core, control surfaces) is deterministic and regenerable by running the notebook top to bottom. Tested with Python 3.10+.

## Key results (regenerated by the notebook)

- Anchors: uniformly strong → Low, uniformly moderate → Moderate, uniformly poor → Critical
- Convergent validity: Spearman ρ ≈ 0.89 against both independent references; references mutually consistent (Cohen's κ ≈ 0.68)
- Monotonicity satisfied in ~97% of trials
- Rough-set core = all eight factors (formal non-redundancy of the taxonomy)

## Disclaimer

This repository accompanies a methodological framework paper. Case profiles are synthetically generated within the notebook; the reference instruments are operationalized from published models cited in the manuscript. The framework validates methodological convergence and formal behaviour, not empirical field accuracy; primary expert and field validation are identified as future work.
